# Supplementary Data S1

Read `Supplementary_Data_S1.xlsx` for the summary tables, labels, uncertainty definitions and source map. The complete 14,601-row, 21-column manifest is in `Supplementary_Data_S1_manifest.tsv.gz`. It is a gzip-compressed UTF-8 tab-separated file and can be read with Python csv/gzip or standard dataframe software. No raw photographs are redistributed.
