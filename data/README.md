# Derived data

The files in `derived/` are compact, non-image outputs from the final executed workflow. `Supplementary_Data_S1.xlsx` contains the reviewer-facing archive inventory, lineage and split audits, benchmark metrics, matched-removal analyses, shortcut controls, end-to-end sensitivity results and a compact 14,601-row manifest. CSV/TSV files mirror the principal public tables for programmatic use.

Raw photographs, annotations and model caches are not redistributed.
