# Public data sources

The downloader retrieves two repository records by API identifier:

- Figshare article `31294003`, a consolidated set of public cacao disease image archives used for provenance reconstruction.
- Zenodo record `17716661`, **CocoaMoniliaDataSet**, DOI `10.5281/zenodo.17716661`.

The raw archives are not included here. API responses, file sizes and source-provided checksums are saved during download. All source images and annotations remain governed by their original repository and archive-specific terms.
